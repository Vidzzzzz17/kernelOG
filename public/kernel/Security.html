Security

Security

Security depends on how Kernel is installed, configured, and operated.

Security considerations

01Kernel sends prompts to a local model running on the user’s computer. Conversations are stored in the database configured by the person running Kernel; the database may be hosted separately from the user’s device.

02The person operating Kernel is responsible for securing the computer, Ollama service, database, network access, backups, and software updates in their deployment.

03This page does not claim a security audit, certification, or compliance status. For security questions, contact substrate.devs@gmail.com.
