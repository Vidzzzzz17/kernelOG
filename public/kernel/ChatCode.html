Write a function that removes duplicates from a list but keeps the original order.
Here’s a small function that does it in a single pass:
pythonCopy
def dedupe(items):
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result
It remembers what it has already seen in a set, so each check is fast, and it adds only the first copy of every item.
